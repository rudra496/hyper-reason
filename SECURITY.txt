2. REPORTING A VULNERABILITY
----------------------------------------------------------------------------------------------------
We take the security of HyperReason very seriously. If you discover a security vulnerability, please 
do NOT open a public issue. Instead, send an email directly to:

Primary Contact: rudrasarker130@gmail.com
Alternate Contact: rudrasarker125@gmail.com

Please include the following details in your report:
- Type of issue (e.g., buffer overflow, arbitrary code execution, token memory leak)
- Step-by-step instructions to reproduce the issue
- Affected python versions and dependencies

3. RESPONSE TIMELINE
----------------------------------------------------------------------------------------------------
- Initial Acknowledgment: Within 24 hours of report receipt.
- Assessment & Triage: Within 72 hours.
- Security Patch Release: Within 7 business days for critical vulnerabilities.
