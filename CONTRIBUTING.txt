====================================================================================================
                              CONTRIBUTING GUIDELINES
====================================================================================================
Project: HyperReason (https://github.com/rudra496/hyper-reason)
Author: Rudra Sarker (Rudra Sir) [https://github.com/rudra496]

Thank you for considering contributing to HyperReason!

1. HOW TO SUBMIT CONTRIBUTIONS
----------------------------------------------------------------------------------------------------
1. Fork the repository: https://github.com/rudra496/hyper-reason
2. Create a feature branch: git checkout -b feature/my-new-feature
3. Ensure all code adheres to PEP 8 standards and includes complete docstrings.
4. Run unit test suite: PYTHONPATH=. python3 tests/test_full_suite.py
5. Commit your changes: git commit -m "feat: add support for custom value heads"
6. Push to your branch and open a Pull Request against `main`.

2. CODE STYLE & VERIFICATION REQUIREMENTS
----------------------------------------------------------------------------------------------------
- All code must pass existing unit tests without failure.
- Avoid introducing external unverified dependencies; keep the core framework pure Python / PyTorch.
- Include unit tests for any new module or feature under `tests/`.
