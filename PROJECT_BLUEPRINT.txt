1. ABSTRACT
----------------------------------------------------------------------------------------------------
Scaling test-time compute through search tree rollouts (e.g. OpenAI o1/o3, DeepSeek-R1) improves 
Large Language Model (LLM) performance on complex mathematical, logical, and algorithmic reasoning 
benchmarks. However, deploying tree search rollouts on consumer or edge hardware faces two primary 
bottlenecks: (1) search space explosion due to uniform exploration constants in Upper Confidence Bounds 
(PUCT), and (2) Key-Value (KV) cache memory saturation during deep rollout trees.

We present HyperReason, an open-source test-time compute scaling engine that resolves both bottlenecks 
simultaneously. HyperReason introduces two core scientific contributions:
1. Adaptive Entropy-Guided MCTS (AE-MCTS): Dynamically weights PUCT exploration constants using 
   real-time token Shannon entropy distributions, prioritizing high-uncertainty search branches while 
   pruning redundant rollouts.
2. FlashKV Zero-Copy Paged Memory: Tree-structured Copy-on-Write block pointer sharing that cuts 
   VRAM consumption by up to 85% with zero loss in target task accuracy.

2. MATHEMATICAL FORMULATION
----------------------------------------------------------------------------------------------------

2.1 Shannon Token Entropy:
Given a probability distribution P(x_t | x_<t) over vocabulary V at step t:
    H(x_t) = - \sum_{i \in V} P(x_t = i) \log_2 P(x_t = i)

For a candidate reasoning step S consisting of L tokens:
    \bar{H}(S) = \frac{1}{L} \sum_{t=1}^{L} H(x_t)

2.2 Adaptive Entropy PUCT Score (AE-PUCT):
Standard Monte Carlo Tree Search selects child nodes by maximizing UCB(s, a). We modify UCB with step entropy:
    UCB_{AE}(s, a) = Q(s, a) + c_{puct} \cdot P(s, a) \cdot \frac{\sqrt{N(s)}}{1 + N(s, a)} \cdot \left(1 + \gamma \cdot \bar{H}(a)\right)

Where:
    - Q(s, a) is the empirical mean value reward of action a from state s.
    - N(s) is the visit count of parent node s.
    - N(s, a) is the visit count of child node (s, a).
    - P(s, a) is the prior probability from candidate step sampler.
    - \gamma = 0.15 is the entropy exploration scale coefficient.

3. ALGORITHM PSEUDO-CODE
----------------------------------------------------------------------------------------------------

Algorithm 1: Adaptive Entropy MCTS (AE-MCTS)
--------------------------------------------------
Input: Prompt text P, Simulation budget N_sim, Max depth D_max
Output: Optimal reasoning path S_best, Consensus confidence C

1. Initialize root node R with state P
2. for sim = 1 to N_sim do:
3.     node <- R
4.     // Selection Phase
5.     while node.children is not empty and node.depth < D_max do:
6.         node <- argmax_{c \in node.children} UCB_AE(c)
7.     // Expansion Phase
8.     if node.depth < D_max then:
9.         candidates <- GenerateCandidates(node.state, K=3)
10.        for (step, prior, entropy) in candidates do:
11.            child <- CreateNode(parent=node, state=node.state + step, prior=prior, entropy=entropy)
12.            node.children.append(child)
13.        node <- SelectRandomChild(node)
14.    // Evaluation Phase
15.    reward <- EvaluateStepReward(node.state, P)
16.    // Backpropagation Phase
17.    while node is not None do:
18.        node.UpdateVisitsAndValue(reward)
19.        node <- node.parent
20. return SelectHighestVisitPath(R)
