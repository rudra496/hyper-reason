VIRAL_LAUNCH_STRATEGY.txt  —  REVISED for the honest v2 (2026-08-10)
====================================================================

The original version of this file pitched launching on fabricated v1.x claims
("beats DeepSeek-R1", "96.4% GSM8K"). That is off the table — those numbers
were invented. Launching hype on fake benchmarks gets a repo demolished on
HN/r/LocalLLaMA within hours and destroys the author's credibility.

The v2 launch angle is the opposite and it is a stronger, rarer hook:

  "HyperReason is the test-time-search repo that publishes the eval where it
   LOST to greedy — real engine, real model calls, raw JSONL, no fake fallbacks."

In an era of benchmark fraud, radical honesty + a genuinely-working in-browser
demo is the differentiator. The credibility IS the virality.

Launch checklist (honest):
  [x] Engine actually drives a real model (GLM live-tested).
  [x] Real GSM8K-mini eval with raw per-problem JSONL + aggregator (eval/).
  [x] Pre-registered eval config (eval/CONFIG.md) + changelog.
  [x] Interactive in-browser demo of the real engine (no key, no CDNs).
  [x] JS<->Python parity test for the browser port.
  [x] Honest README that states the loss, not a fake win.
  [ ] Record a 15s screen-capture of the live demo tree animation.
  [ ] Submit to r/LocalLLaMA as "Show: an honest test-time-search engine
      (with the eval where MCTS lost to greedy)".
  [ ] HN title: "Show HN: HyperReason — test-time MCTS that actually calls the
      model (and reports when it underperforms greedy)".
  [ ] Pin the repo; link the live demo at the top of the README.

Never: claim SOTA, invent numbers, tune the eval until MCTS wins, or restore a
silent fake fallback. The honesty contract in README.md is binding.
