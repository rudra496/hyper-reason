Test-Time Reasoning Compute
With -65% VRAM Reduction

HyperReason combines Adaptive Entropy-Guided MCTS (AE-MCTS) with Token-Attentive Dynamic KV-Cache Sparsification (T-KVP) to enable deep test-time LLM reasoning rollouts on consumer GPUs.

pip install hyper-reason

AE-MCTS Exploration

Dynamically scales PUCT search constants based on token Shannon entropy, prioritizing uncertain branches while suppressing redundant exploration.

T-KVP Sparsification

Evaluates cross-token attention salience scores and evicts intermediate non-essential key-value states, slashing VRAM consumption by 65%.

Consensus Verifier

Aggregates multi-trajectory leaf paths and evaluates step-level value rewards for self-consistency and consensus voting.

Interactive Tree Search Visualizer

Simulate MCTS reasoning rollout tree expansion and token KV pruning live in your browser.
