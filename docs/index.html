How it works — three honest steps

① Sample

At each node the engine asks the model for K candidate next-steps. Priors and entropy come from those real samples — never hardcoded.

② Search

AE-PUCT selection balances value and sample-diversity entropy (a logprob-free uncertainty proxy, since the gateway returns none). Bounded budget: sims × K calls.

③ Vote

The final answer is majority-vote (self-consistency) over the terminal trajectories the model actually produced. Confidence = agreement fraction.

④ Account

FlashKV then projects CoW paged-cache savings over the real tree — in tokens (model-agnostic) and projected MB behind a disclosed bytes/token.

Run with a real model

The browser demo uses a deterministic sampler on purpose — it keeps this page keyless and instant. For genuine reasoning, the package drives a real model server-side (your key never touches this static page).

Python (1 line)

from hyper_reason import wrap_model, GLMBackend
wrap_model(GLMBackend()).reason("…")

Ollama (local)

wrap_model(OllamaBackend("llama3.1:8b")) — runs fully offline on your GPU.

HuggingFace

TransformersBackend("Qwen/Qwen2.5-1.5B-Instruct") — needs pip install hyper-reason[transformers].

The honesty contract

v1.x of this repo shipped fabricated benchmarks (a wrapper that never called a model). v2 is a full rebuild bound by these rules:

Real or labeled

Every number is either produced by a runnable command whose config is given, or explicitly tagged projected / simulated with the assumption stated.

No fake fallbacks

Missing model/daemon → the backend raises, never returns invented text or token counts. (v1.x silently faked an Ollama response when offline.)

Entropy, stated

“sample-diversity entropy (no logprobs)” — not “token entropy”. The gateway returns no logprobs, so we don’t pretend otherwise.

Verifiable

Raw per-problem JSONL + aggregator are in eval/; a JS↔Python parity test pins the browser port to the package.
