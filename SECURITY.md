# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in HyperReason, please do **NOT** open a public issue. Send an email directly to:

* Primary: `rudrasarker130@gmail.com`
* Alternate: `rudrasarker125@gmail.com`

We will acknowledge receipt within 24 hours and issue a patch within 7 business days.
