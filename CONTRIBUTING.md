# Contributing to HyperReason

Thank you for contributing!

## Development Workflow

1. Fork the repo: `https://github.com/rudra496/hyper-reason`
2. Create a branch: `git checkout -b feature/my-feature`
3. Run unit tests: `PYTHONPATH=. python3 tests/test_full_suite.py`
4. Submit a Pull Request against `main`.
